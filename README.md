# Феррофлюид

Музыкальный визуализатор: капли магнитной жидкости в неоновом окне колонки реагируют на музыку.
Работает в браузере и устанавливается как приложение (PWA) на Android, iPhone и компьютер.

## Публикация на GitHub Pages

1. Создайте **публичный** репозиторий, например `ferrofluid`.
2. Загрузите в него **всё содержимое этой папки** (Add file → Upload files), включая папку `icons`
   и файл `.nojekyll`. Файлы должны лежать в корне репозитория, а не во вложенной папке.
3. Settings → Pages → Source: **Deploy from a branch**, ветка **main**, папка **/ (root)** → Save.
4. Через 1–2 минуты сайт откроется по адресу `https://ЛОГИН.github.io/ferrofluid/`.

## Установка как приложение

- **Android (Chrome):** кнопка «Установить» в панели или меню ⋮ → «Установить приложение».
- **iPhone / iPad (Safari):** «Поделиться» → «На экран Домой».
- **Компьютер (Chrome / Edge):** значок установки в адресной строке или кнопка «Установить».

## Обновление

После изменения любого файла увеличьте номер в первой строке `sw.js`
(`ferrofluid-v1` → `ferrofluid-v2`), иначе установленное приложение может показывать старую версию.

## Звук

| Где | Источники |
|---|---|
| Chrome / Edge на компьютере | звук устройства (вкладка или весь экран), микрофон, файл |
| Safari, Firefox, телефоны | микрофон, файл |

Микрофон и захват звука работают только по адресу `https://` — GitHub Pages даёт его автоматически.
